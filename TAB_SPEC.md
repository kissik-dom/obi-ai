# DOC 4: TAB_SPEC.md - 24 Core Tabs Extensible to 28 Tabs

## 1. Universal 10-Section Tab Grammar (Identical Across Every Tab)

To guarantee zero UI inconsistency, every single tab (`1..24` and extensible `25..28+`) exposes the exact same 10 REST endpoints in FastAPI and the exact same 10 interactive workspace panels in React:

1. `Chat` (`POST /api/tabs/{slug}/chat`, `GET /api/tabs/{slug}/chat`) - Domain-routed LLM chat with automatic sandbox provisioning and GOLD `COPY` buttons.
2. `Agents` (`GET /api/tabs/{slug}/agents`, `POST /api/tabs/{slug}/agents`) - Assigned Sovereign Agents + Hermes Swarm specialists with per-agent toggle.
3. `Open Tasks` (`GET /api/tabs/{slug}/open-tasks`, `POST /api/tabs/{slug}/open-tasks`) - Active tasks (`queued`, `running`, `waiting`, `approval_required`, `blocked`, `scheduled`, `recurring`).
4. `Completed Tasks` (`GET /api/tabs/{slug}/completed-tasks`) - Unified single-batch deliveries (`completed`, `failed`, `cancelled`) linked to `s3://kingdom-finished/`.
5. `Training` (`GET /api/tabs/{slug}/training`, `POST /api/tabs/{slug}/training`) - Qdrant 768d cosine corpus ingestion & Ling-3.1-Flash 1M-token indexing.
6. `Knowledge` (`GET /api/tabs/{slug}/knowledge`, `POST /api/tabs/{slug}/knowledge`) - Semantic vector retrieval, identity bibles, and OpenTimestamps/IPFS hashes.
7. `Files` (`GET /api/tabs/{slug}/files`, `POST /api/tabs/{slug}/files`) - Atomic MinIO `s3://kingdom-requests/` and `s3://kingdom-finished/` file explorer.
8. `Tools` (`GET /api/tabs/{slug}/tools`, `POST /api/tabs/{slug}/tools`) - Collapsible Category A-M open-source tools mapped to this tab with lazy-loaded runner.
9. `Outputs` (`GET /api/tabs/{slug}/outputs`) - Unified one-batch deliverables (`.mp4`, `.zip`, `.pdf`, `.csv`, FreeCAD `.step`, BOM, Police Audit PDF).
10. `Settings` (`GET /api/tabs/{slug}/settings`, `POST /api/tabs/{slug}/settings`) - Priority LLM override, guardrail filter, sandbox equip toggle, and `ENABLE_*` flags.

Also each of the 24 core tabs is mounted at its direct router path (`/api/home/*`, `/api/llm/*`, `/api/research/*`, ..., `/api/security/*`) as well as `/api/tabs/{slug}/*`.
